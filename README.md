# Projet Santé Publique — Akieni Academy

Projet data dédié à l'analyse du système de santé publique du Congo (hôpitaux, médicaments, indicateurs OMS). Le fichier `sante_variables.py` est le module fondateur : il centralise les constantes métier et les variables de 5 hôpitaux et 5 médicaments essentiels, réutilisées par tous les scripts du projet. Chaque semaine apporte de nouvelles fonctionnalités (conditions, fonctions, classes, puis tables SQL) construites sur cette base commune.

## Exécution
```bash
python sante_variables.py
```
